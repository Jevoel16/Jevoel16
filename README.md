### 💡 Skills & Capabilities

- **Full-stack web development:** Building REST APIs with Express and FastAPI, connected to React and Next.js frontends
- **Authentication & access control:** JWT, bcrypt password hashing, Google OAuth 2.0 sign-in, role-based permissions and admin approval steps
- **Auditability:** Audit trails that record who did what and when
- **Working with many databases:** Document (MongoDB), relational (MySQL), graph (Neo4j and Cypher), key-value (Redis) and wide-column (Cassandra)
- **Network programming:** HTTP and WebSocket servers written from scratch, real-time broadcasting, and WebRTC video calls
- **Machine learning pipelines:** Data cleaning, feature engineering, training, evaluation, forecasting and explaining model results with SHAP
- **API integration & data visualization:** Pulling in outside APIs, caching responses, handling rate limits, and showing results in interactive charts and maps
- **Documentation:** Clear READMEs with setup guides, API references and screenshots
